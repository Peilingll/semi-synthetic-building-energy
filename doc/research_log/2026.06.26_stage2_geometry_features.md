# 2026.06.26 — Stage 2: raising the GT ceiling with BAG/EP geometry features

## Motivation

The S_full GT ceiling (type/year/floor/U/city) is low (macro-F1 0.180). Advisor
asked to push toward higher accuracy. Strategy: find which extra BAG/EP registry
features raise the ceiling, THEN ask which are SVI-extractable (year is "invisible"
yet recoverable from facade cues — same logic may apply to building shape/size).

All experiments: dev set n=8,068, 5-fold OOF LightGBM (fixed HP, class_weight=None),
same protocol as Stage 2. GT features only (no vision). Coverage ~99.9%.

## CRITICAL: leakage columns excluded

EP-Online numeric outputs are the energy calculation itself → using them = circular
leakage. **Excluded**: `PrimaireFossieleEnergie`, `Energiebehoefte`, `Warmtebehoefte`,
`BerekendeCO2Emissie`, `BerekendeEnergieverbruik`, `AandeelHernieuwbareEnergie`,
`EnergieIndex`. (PrimaireFossieleEnergie is used ONLY as the regression target, never
as a feature.)

**compactheid is the dominant single feature** (+0.085, ~2× the next). The
exposed/shared-wall and volume features are essentially compactheid's components —
compactheid integrates them into one stronger signal. volume alone is weak; its value
is as the denominator of compactheid.

## Cumulative ceiling (useful features stacked)

| Feature set | macro-F1 | κ | acc |
|---|---:|---:|---:|
| S_full (type/year/floor/U/city) | 0.180 | 0.187 | 0.349 |
| + compactheid | 0.265 | 0.355 | 0.366 |
| + compactheid + floor_area | 0.271 | 0.385 | 0.373 |
| + compactheid + floor_area + shared | 0.284 | 0.386 | 0.383 |
| ALL useful geometry | 0.284 | 0.399 | 0.391 |

**Ceiling with all registry+geometry = macro-F1 0.284 / κ 0.399 / acc 0.391**
(from 0.180: macro-F1 +57%, κ +114%). Diminishing returns: compactheid alone
captures most (0.180→0.265); everything else adds only +0.019.

## Classification vs regression-to-kWh (with the new geometry features)

| Method (ALL useful features) | macro-F1 | κ | acc | kWh MAE |
|---|---:|---:|---:|---:|
| direct classification | 0.295 | 0.407 | 0.397 | — |
| regression PF kWh → bin to A–G | 0.264 | **0.469** | 0.398 | 47.0 |

(Note: this run's classification macro-F1 0.295 > the 0.284 above because the
regression run dropped buildings with no valid PF target, slightly changing the set.)

- **accuracy unchanged** (~0.40) either way.
- **Regression now WINS on κ** (0.469 vs 0.407) — opposite of the earlier no-geometry
  result (where regression lost). Once features are strong enough (compactheid), the
  kWh regression ranks buildings better along A–G; binning loses a little macro-F1.
- Energy class is intrinsically a discretised continuous quantity, so regression
  respects ordinality → better κ, at the cost of small-class macro-F1.

## Findings

1. **compactheid (building shape / surface-to-volume ratio) is the single strongest
   non-trivial feature** for downstream EPC — stronger than floor area. Physically
   sound: heat loss scales with exposed surface, not just size.
2. **The "strong features are all SVI-invisible" worry is broken.** The strongest
   feature (compactheid) IS partly SVI-visible (terraced vs detached, shape, frontage
   width — advisor's "row houses have lower area" intuition is exactly compactheid).
   And compactheid HAS a GT (computed from BAG surface/volume) → a full "can SVI
   extract compactheid" experiment is possible (unlike WWR/material which lack GT).
3. **Registry+geometry ceiling tops out at acc ~0.39 / macro-F1 0.28 / κ 0.40** on
   this dev set. 70% accuracy is not reachable here without WOZ value / CBS socio-
   economic features (Hettinga 2023), which are outside the SVI scope.
4. **Regression-to-kWh helps κ (ranking) but not accuracy**, once geometry features
   are present.

## Implication for the thesis / next steps

- New positive SVI direction: extract **compactheid / shape / attachment** from
  imagery (it has GT and is the strongest feature), rather than chasing precise area.
- WWR / material: no GT, but testable as features without GT (does adding a vision-
  estimated WWR/material help downstream?). material has OpenFACADES predictions
  available; WWR needs a VLM/CV estimate.
- Decide with advisor whether 70% target means accuracy (needs non-SVI features,
  off-topic) or macro-F1/κ (capped by task), and whether to add WOZ/CBS as a pure
  "registry ceiling" reference.
