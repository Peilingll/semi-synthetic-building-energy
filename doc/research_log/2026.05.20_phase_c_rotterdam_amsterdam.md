## Amsterdam two-phase run, capped at 14 cells

### Phase 1: full launch + first-cell timeout crash

- Command: `--city amsterdam --min-residential-per-cell 30` (Patch #6 +
  density cut applied).
- First cell `cell_0578` (n_resid=1256) exceeded `SUBPROCESS_TIMEOUT_S=3600`.
  The uncaught `subprocess.TimeoutExpired` killed the entire runner.
- **Bug fix**: `run_one_cell()` now wraps both subprocess.run calls in
  `try/except subprocess.TimeoutExpired`, marks the cell as `failed`, and
  continues to the next cell. `SUBPROCESS_TIMEOUT_S` raised from 3600 to 7200.

### Phase 2: capped run

- Restart: `--city amsterdam --min-residential-per-cell 30 --max-cells 35`.
- Resume skipped the 7 done + 1 failed cells from Phase 1.
- Stopped manually after cell 14 completed, on user instruction.
- Rationale: 8,026 buildings already vastly exceeds the thesis ablation
  requirement (3–5 images/building target). Continuing would only widen the
  Amsterdam-dominance imbalance (67 % → 85 %+).
