# 2026.06.22 — M2-VLM: zero-shot InternVL3 asked directly for A–G

Completes the M2 (end-to-end) row for the third paradigm. Unlike DINOv2/ResNet
(trained neural head on energy), the VLM's end-to-end analogue is a zero-shot
prompt asking directly for the energy label — no training, matching the VLM's
deployment scenario (Gap 1, no labelled data).

## Setup

- `src/stage3/m2_vlm_runner.py`: reuses Stage 1 InternVLChat + top-3 manifest;
  new prompt asks ONLY for `energy_label` ∈ A–G (no type/year/floor, no TABULA),
  with visible-cue guidance (glazing, solar panels, renovation, facade age) but
  NO kWh boundaries (variant 1, to avoid v2-style anchoring/banding).
- 5,261 hold-out images, parse_ok 100%, ~0.8 s/img.
- `src/stage3/m2_vlm_eval.py`: per-pand_id majority vote (tie → more efficient),
  same hold-out common set (n=2,016).

## Result (hold-out, n=2,016)

| Route | macro-F1 | κ | acc |
|---|---:|---:|---:|
| M1 (GT ceiling) | 0.172 | 0.233 | 0.356 |
| M3-VLMv3 (decomposed ZS) | 0.137 | 0.041 | 0.278 |
| **M2-VLM (direct ZS)** | **0.015** | **0.006** | **0.046** |

Prediction distribution: **F = 1,992 / 2,016 (99%)**, B 21, G 2, C 1, A/D/E 0.

## Interpretation

1. **Zero-shot VLM directly predicting EPC fully degenerates** — 99% predict F,
   macro-F1 0.015, accuracy 0.046 (below the 1/7 random rate, because it locks
   onto one rare class). The model has no genuine concept of the Dutch energy
   label; it applies a crude "old Dutch brick house → inefficient → F" mapping.

2. **For the VLM, decomposed >> end-to-end** (M2-VLM 0.015 vs M3-VLM 0.137) — the
   OPPOSITE of the trained backbones, where end-to-end ≥ decomposed. Asking the
   VLM for concrete visible attributes (type/year) it can estimate, then deriving
   the label, is far better than asking for the abstract label directly.

3. **The unifying M2 story**: end-to-end recovers signal ONLY when the head is
   trained on the energy label.

   | M2 end-to-end | trained on label? | result |
   |---|---|---|
   | DINOv2 / ResNet | yes (neural head) | matches GT ceiling M1 |
   | VLM | no (zero-shot) | degenerates (all-F) |

   So "end-to-end vision ≈ registry ceiling" requires task-specific training;
   pure zero-shot VLM has no usable internal EPC knowledge. Consistent with the
   Zotero "否定VLM對EPC準確度" line (Mayer et al. etc.).

## Thesis use

- M2-VLM is a clean negative control: justifies why the trained M2 (not zero-shot)
  is the deployable end-to-end route, and bounds the zero-shot VLM's competence —
  it can zero-shot extract *attributes* (Stage 1 type/year usable) but cannot
  zero-shot judge the *energy label*.
