### Three install / runtime blockers

| # | Blocker | Resolution |
|---|---|---|
| 1 | `streetlevel>=0.6` pulls in `pyfrpc`, whose Cython C extension requires MSVC Build Tools (not installed on this Windows machine) | Pinned `streetlevel==0.5.0` via pip constraint; 0.5.0 does not depend on pyfrpc. zensvi's Mapillary downloader path is unaffected |
| 2 | `OpenFACADES/src/openfacades/footprint/downloader.py:70-71` used the osmnx < 2.0 `features_from_bbox(bbox=[N,S,E,W])` signature, but zensvi requires `osmnx>=2.0`. Result: bbox interpreted as invalid bounds, process consumed 8 GB RAM attempting to fetch a very large area | Replaced with `ox.features_from_bbox(tuple(bbox), tags)`, passing `(left, bottom, right, top)` WGS84 tuple directly |
| 3 | osmnx 2.0 renamed the OSM identity column from `osmid` to `id`. `downloader.py`'s `selected_columns` filter listed only `osmid`, so after `reset_index` the `id` column was dropped and `building_id` became null for 68/69 footprints | Added `'id'` to `selected_columns`; `col_names` already mapped `'id' → 'building_id'` |

Both downloader.py patches were applied to the local `D:/ITBE/Thesis/OpenFACADES/` clone. The clone is outside this repo, so upstream `git pull` may revert the patches. An upstream PR is warranted.
