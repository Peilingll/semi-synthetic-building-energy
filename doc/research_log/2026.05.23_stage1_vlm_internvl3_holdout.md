# 2026.05.23 — Stage 1 VLM: InternVL3-2B zero-shot hold-out results

## Motivation

With Phase B (DINOv2 frozen + MLP) complete, fill the 4th cell of the spec
§3.2.3 model matrix with a zero-shot VLM. The user picked InternVL3-2B over
Gemini (local, no API key, open source, reproducible). spec §3.2.1 warns
against the OpenFACADES fine-tuned variant due to category mismatch, so we
use the original `OpenGVLab/InternVL3-2B` with a hand-written prompt aligned
to the 4-class Dutch typology.

Scope: hold-out only — 2,018 buildings × top-3 images = 5,261 images. Dev
8,068 inference for the Stage 3 M3 route is deferred to Phase C.

## Setup

- conda env `D:\conda_envs\openfacades` (InternVL custom model code + deps)
- Model: `OpenGVLab/InternVL3-2B`, bfloat16, ~4 GB VRAM
- Top-3 images per building: manifest `image_idx` 0-2 (already sorted by
  `aov_geo` DESC at manifest build time)
- Resume: 100-image partial parquet checkpoints

## Prompt iteration

**v1 (6 fields with wwr)** — Smoke 20 images: parse_ok 90 %, wwr anchored to
0.35 in 18/20, MFH over-predicted in 9/20.

**v2 (5 fields, wwr dropped)** — User decision + anti-anchor hardening:

```text
You MUST provide values for ALL fields. NEVER return null.
"building_type":
    SFH = standalone with garden
    TH  = shares side walls with neighbors
    AB  = multi-unit residential. DEFAULT for any multi-unit.
    MFH = rare collective housing (rooming, dorm, elderly care).
"construction_year": Do NOT default to period boundary years
    (1964, 1975, 1991, 1992, 2005, 2014).
+ construction_period (NL.01-NL.06), num_floors, facade_material
```

Re-smoke 20: parse_ok **100 %**, type 19 AB + 1 TH on an all-AB GT slice,
throughput 5.5 → 2.5 sec/img.

**WWR removal trade-off**: the Phase 3 semi-synthetic equation
`actual_window_area = vlm_wwr × 3d_wall_area` (spec H3 interaction) is no
longer available. Accepted as a paper limitation.

## Failure mode analysis

1. **AB-default bias too strong**: prompt v2's "AB is DEFAULT for
   multi-unit" produced 88 % AB predictions. The dominant-class match
   inflates accuracy while macro_f1 of 0.27 exposes that TH / SFH are
   barely recovered.
2. **Year clusters at three values (1975 / 1991 / 1992)**: the model
   anchors on period boundaries instead of inferring from facade cues.
3. **period_acc 0.049 < random 0.17**: VLM systematically under-estimates
   how old the Dutch housing stock is; most NL.01 (≤1964) GT gets pushed
   to NL.03 / NL.04 (1975-2005).
4. **Internally consistent, externally wrong**: type vote_share averages
   0.94 across the 3 images per building; year_period internal
   consistency 0.91. The model is confident — confidently wrong.
5. **Floors is the only acceptable head**: MAE 0.73, 93.4 % within ±1.

## Verdict

The VLM zero-shot row contributes to the paper as a **lower-bound
baseline**, inverting spec §3.2.3's original framing of "VLM as
upper-bound semantic understanding". The substantive message for the
paper is:

> A generic 2 B-parameter VLM, applied zero-shot, is materially worse on
> 4-class Dutch typology and precise construction year than a frozen
> DINOv2 backbone with a small MLP head trained on the same SVI data.
> This supports the broader thesis framing that pure zero-shot VLM is
> insufficient; supervised visual training plus administrative-registry
> joins are necessary for an energy-archetype pipeline.
