# 2026.06.18 — Aligned M2 (paper version): DINOv2 → energy label

Supersedes the frozen-probe smoke (`2026.06.18_stage3_m2_endtoend.md`). This is
the M2 used in the thesis.

## What "aligned" means

M2 must differ from M3 ONLY in "end-to-end vs decomposed", so M2 reuses Stage 1's
architecture + training recipe, changing only the output (energy label, no
TABULA/LightGBM):

- `DINOv2FrozenEnergy` = same frozen DINOv2 backbone + same trunk (768→256, GELU,
  Dropout) as `DINOv2FrozenMLP`, single 7-class energy head.
- class-weighted CE, AdamW (lr 5e-4, wd 0.01), cosine, early-stop on val energy
  macro-F1, 5-fold, best-fold hold-out (same protocol as `eval_holdout.py`).

### Efficiency fix (why cached)

The frozen backbone never learns, so re-forwarding all images every epoch (needed
only for train-time augmentation) is wasted — the full path measured ~10 h for
5 folds. Instead: extract embeddings ONCE (`extract_embeddings.py`), then train
the identical neural head on cached embeddings → seconds. **Only deviation from
Stage 1: no train-time augmentation** (marginal for a frozen backbone). Mode:
`m2_aligned.py --cached`.

## Results (hold-out, n=2,016)

| Route | macro-F1 | κ | acc |
|---|---:|---:|---:|
| M1 (GT ceiling) | 0.172 | 0.233 | 0.356 |
| M3-DINOv2 (decomposed) | 0.150 | 0.083 | 0.292 |
| **M2-DINOv2 (aligned)** | **0.213** | **0.236** | 0.266 |

- M2 − M3: **+0.063 macro-F1, +0.153 κ** — end-to-end clearly beats the decomposed
  archetype route.
- M2 − M1: **+0.041 macro-F1, +0.003 κ** — end-to-end vision matches (slightly
  exceeds) the GT registry ceiling on the principled metrics.
- M2 lower raw accuracy (0.266) is the class-weighted CE trade (spreads to small
  classes); macro-F1/κ are the metrics that matter for this imbalanced ordinal task.

## Robustness

The conclusion (M2 ≫ M3, M2 ≈/> M1) holds across two independent head/weighting
choices:
- aligned neural head, class-weighted CE: 0.213 / κ 0.236
- frozen-probe LightGBM, class_weight=None (smoke): 0.176 / κ 0.208
Both beat M3 (0.150 / κ 0.083) and match/exceed M1 (0.172 / κ 0.233). So the
finding is not an artefact of the head or the class weighting.

## Caveat for fair reading

M2 uses class-weighted CE (aligned to Stage 1); M1/M3 use LightGBM
class_weight=None. Part of M2's macro-F1 edge may reflect weighting. But: (a) κ,
which weighting tends to hurt, is still ≥ M1; (b) the no-weight smoke M2 also
beats M3 and matches M1. So "end-to-end ≥ decomposed, ≈ registry ceiling" is robust.

## Thesis takeaway (RQ2, final)

The archetype decomposition (image → type/year/floor → TABULA → LightGBM) is the
binding constraint, not vision: end-to-end vision recovers the lost signal and
equals the registry-attribute ceiling. All routes plateau at a low absolute
ceiling because the true determinants (insulation, systems, area) are visible to
neither registry attributes nor the street. Deployment: for the energy-label task,
use end-to-end vision over the archetype route; the archetype/attribute pipeline's
value is interpretable attribute extraction (RQ1), not label accuracy.
