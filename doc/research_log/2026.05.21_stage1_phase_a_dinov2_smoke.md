## Dataset / Splits

- StratifiedGroupKFold(n_splits=5, group=pand_id, stratify=Energieklasse)，random_state=42
- 173 棟 → 每 fold val 34-35 棟，train 138-139 棟
- 警告：`Energieklasse` 細類 A+++（1 棟）/ A+（3 棟）/ A++（3 棟）觸發 sklearn 「class < n_splits」warning，benign
- Augmentation（per spec §3.2.4）：`RandomResizedCrop(224, scale=(0.7,1.0))` + `RandomHorizontalFlip` + `ColorJitter(0.2,0.2,0.2)`，無 vertical flip
- Normalize: ImageNet mean/std（對齊 DINOv2 預訓練）

**fold 0**：train 139 棟 / 880 圖，val 34 棟 / 190 圖。

DINOv2 預期 518×518 輸入；改用 `dynamic_img_size=True` 讓它接受 224×224（時序位置嵌入從 37×37 內插到 16×16）。

## 模型

`DINOv2FrozenMLP`：

```
images [B, 8, 3, 224, 224]
  ↓ backbone (frozen, no_grad) — vit_base_patch14_dinov2.lvd142m
features [B, 8, 768]
  ↓ mask-aware mean-pool（過濾 padded slots）
pooled [B, 768]
  ↓ Linear(768→256) + GELU + Dropout(0.2)
trunk [B, 256]
  ↓ 三條獨立分支
head_type   [B, 4]  →  CE loss
head_year   [B, 1]  →  MSE loss（standardize）
head_floors [B, 1]  →  MSE loss（standardize）
```

可訓練參數: **198 k**（trunk + 3 個 head）。backbone 86.6 M 全 frozen。

## 觀察

1. **Pipeline 端到端通過**：GT builder → splits → dataset → model → train → eval 五個檔案全部 wire 起來無例外，產出符合 spec Table 1 schema 的 metrics.json。Phase A 驗收標準（metrics.json 非 nan、VRAM < 8GB、epoch < 1 min）全部滿足。

2. **SFH 完全無法識別**：8 棟訓練 SFH 樣本 + 5 棟 val SFH 全被預測為 TH。frozen DINOv2 + 8 棟訓練資料對 SFH 而言實質為零樣本學習。Phase B 四城資料量擴大後 SFH 應有上百棟，加上 ResNet/Swin full fine-tune 應大幅改善。

3. **AB 表現出色**：precision 0.90 / recall 0.82 / f1 0.86。AB 樣本充足（112 棟訓練、22 val），DINOv2 frozen feature 已能區分公寓 vs 透天/排屋。

4. **過擬合明顯**：train_acc 12 epoch 內從 0.43 升至 0.88，但 val_f1 卡在 0.30-0.33。139 棟訓練資料明顯不足以餵 198k 參數的 MLP head 學到泛化模式。Phase B 多城資料量、加正則化、降 lr 是顯然路徑。

5. **year MAE 32.7 yr 偏高**：mdae 15.67 yr 說明中位數誤差還可接受，但 mean 被少數大誤差拉高。Delft train 年代 mean=1923 std=48（多集中 1875-1970），val 包含現代建築（>2000）時模型外推差。Phase B 四城年代分布更廣應改善。

6. **floors MAE 0.54 算合理**：97% 預測值在 ±1 樓內，可作為 Stage 3 M3 路線實用輸入。

7. **VRAM 與時間用量保守**：batch=32 只用 3.1 GB / 8 GB，epoch 28 秒。Phase B 在 47k 圖 / 4 城上線性外推 ≈ 47000/1070 ≈ 44x 資料 → ~20 分鐘/epoch。30 epoch × 5 folds × 1 model ≈ 50 小時 GPU；4 model 全套估 100+ 小時，需思考 ResNet/Swin 是否要分次或降規模。
