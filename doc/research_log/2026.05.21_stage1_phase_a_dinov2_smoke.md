## Dataset / Splits

- `StratifiedGroupKFold(n_splits=5, shuffle=True, random_state=42)`, group = `pand_id`,
  stratify = `Energieklasse`
- 173 buildings → each fold ~34–35 val, ~138–139 train
- Warning: rare `Energieklasse` classes (A+++ 1 sample, A+ 3, A++ 3) trigger sklearn's
  "class with fewer members than `n_splits`" warning; benign.
- Augmentation (per spec §3.2.4):
  `RandomResizedCrop(224, scale=(0.7, 1.0))` + `RandomHorizontalFlip` + `ColorJitter(0.2, 0.2, 0.2)`,
  no vertical flip.
- Normalize: ImageNet mean/std (aligned with DINOv2 pretraining).

**Fold 0**: train 139 buildings / 880 images, val 34 buildings / 190 images.

DINOv2 expects 518×518 inputs; setting `dynamic_img_size=True` lets it accept 224×224 by
interpolating the positional embedding grid from 37×37 to 16×16.

## Model

`DINOv2FrozenMLP`:

```
images [B, 8, 3, 224, 224]
  ↓ backbone (frozen, no_grad) — vit_base_patch14_dinov2.lvd142m
features [B, 8, 768]
  ↓ mask-aware mean-pool (excludes padded slots)
pooled [B, 768]
  ↓ Linear(768 → 256) + GELU + Dropout(0.2)
trunk [B, 256]
  ↓ three independent branches
head_type   [B, 4]  →  CE loss
head_year   [B, 1]  →  MSE loss (standardized)
head_floors [B, 1]  →  MSE loss (standardized)
```

Trainable parameters: **198 k** (trunk + 3 heads). Backbone 86.6 M is fully frozen.

## Observations

1. **Pipeline validates end-to-end**. The five files
   (`gt_builder → splits → dataset → models → train → evaluate`) wire together without
   exception and produce a `metrics.json` matching the spec Table 1 schema. Phase A
   acceptance criteria (metrics.json populated, VRAM < 8 GB, epoch < 1 min) all pass.
2. **SFH is unrecoverable here**. With 8 SFH training samples and 5 SFH val samples, all
   5 are predicted as TH. Frozen DINOv2 + 8 examples is effectively zero-shot for this
   class. Phase B four-city data should bring SFH count into the hundreds; combined with
   ResNet/Swin full fine-tune, this should improve sharply.
3. **AB is solid**: precision 0.90 / recall 0.82 / F1 0.86. With 112 train / 22 val
   samples, frozen DINOv2 features already separate apartments from row/single houses.
4. **Clear overfit**. Train acc climbs from 0.43 to 0.88 over 12 epochs while val F1
   plateaus at 0.30–0.33. 139 training buildings underfeed the 198 k MLP head's capacity
   for generalisation. Phase B's bigger pool, plus regularisation and an LR sweep, are
   the obvious levers.
5. **Year MAE 32.7 yr is high**, but median is 15.67 yr — a few large errors pull the
   mean up. Delft train years are concentrated at mean 1923 / std 48 (mostly 1875–1970),
   so the model extrapolates poorly on val buildings > 2000. Phase B's wider four-city
   year distribution should help.
6. **Floors MAE 0.54 is acceptable**: 97 % within ±1, usable as input for the Stage 3
   M3 route.
7. **VRAM and time are not the bottleneck**. batch = 32 uses 3.1 GB / 8 GB and 28 s/epoch.
   Linear scaling to 47 k images across four cities gives ~44× data → ~20 min/epoch.
   A single model 5-fold × 30 epoch run ≈ 50 GPU-hours; four models full Phase B
   ≈ 100+ GPU-hours. ResNet/Swin may need to be staged.
