# 2026-06-06 — Stage 1 VLM prompt v3: hold-out rerun

## Motivation

The v2 hold-out run (2026-05-23) had two dominant failure modes:

1. **Year banding**: predictions clustered on 1975/1991/1992 — year MAE 61.5 yr,
   period_acc 0.049 (below the 1/6 random floor).
2. **AB-default bias**: 88% of buildings predicted AB, macro_f1 0.272.

Diagnosis: the v2 prompt's `construction_period` field listed the TABULA period
boundary years verbatim, anchoring the year output onto them; the "do NOT
default to boundary years" instruction re-fed the same numbers. The
"AB = DEFAULT for any multi-unit" instruction caused the type collapse.

## Prompt v3 changes

- **Removed `construction_period` entirely** — no boundary year appears anywhere
  in the prompt. The TABULA period is now derived downstream via
  `tabula_matcher.classify_period(pred_year)` at the aggregation step, the same
  year-to-period mapping applied to predictions and GT (spec definition).
- **Removed `facade_material`** (no GT to validate it).
- Removed the AB-default instruction; type criteria rewritten around visible
  cues only.
- Output reduced to 3 fields: `building_type`, `construction_year`, `num_floors`.

## Methodology fix: dev-set prompt iteration

v2's prompt was tuned on 20 hold-out buildings (mild test leakage). v3 prompt
iteration used a frozen 200-building dev sample (`dev_sample.py`, seed 42):
AB 80 / TH 60 / SFH 40 / MFH 20, deliberately oversampling minority classes (a
proportional draw would be ~89% AB and could not detect whether the AB bias is
resolved). The hold-out was run exactly once after the prompt was frozen.

## Iteration trace

- **Smoke (20 imgs)**: parse_ok 80% — the model omits `num_floors` and closes
  the JSON early when uncertain. Adding "ALL three keys, in this order; if
  uncertain give your best single estimate — never omit a key" → 20/20.
- **Round 1**: year fixed (boundary predictions 1/504, MAE 34.8, period_acc
  0.578) but type over-corrected: "own front door = TH, not AB" pushed AB
  recall to 9% (61/80 AB→TH); "semi-detached" pulled TH into SFH (40/60).
  Root cause: many narrow historic Dutch city-centre buildings are subdivided
  into apartments (GT=AB) but subdivision is invisible from the facade.
- **Round 2 (final)**: type criteria recast as visible proxies — SFH must be
  free-standing; TH = 2-3 storey row in a residential street; AB cues include
  "narrow historic building of 3+ storeys in a dense city-centre street";
  tie-breaker on storey count / ground-floor shops / street density.
  Dev results: macro_f1 0.237→0.361, AB recall 9%→39%, period_acc 0.60.
  Stopped here to avoid overfitting the prompt to the 200-building sample.

## Hold-out results (n=2,016 of 2,018; 2 dropped)

| model | type_acc | macro_f1 | year_mae | period_acc | floors_mae |
|---|---:|---:|---:|---:|---:|
| DINOv2 frozen | 0.901 | 0.520 | 9.45 | (pending) | 0.377 |
| VLM v2 | 0.774 | 0.272 | 61.49 | 0.049 | 0.734 |
| **VLM v3** | 0.495 | 0.246 | **30.65** | **0.769** | 0.708 |

- 95% CI: type_acc [0.474, 0.515], macro_f1 [0.225, 0.267],
  year_mae [29.7, 31.6], floors_mae [0.677, 0.741]
- parse_ok 99.96% (5,259/5,261); **boundary-year predictions 0/5,259**
- Year detail: RMSE 37.3, MdAE 26, within ±10y 12.0%, within ±20y 31.8%;
  predictions now decade-rounded (1950 37%, 1900 24%, 1850 16%, 1980 11%)
- Floors: exact 39.2%, within ±1 92.5%
- Runtime: 3.25 s/img avg, 4.8 GPU-hr total
- Per-class type f1: AB 0.669 / SFH 0.212 / TH 0.102 / MFH 0.0
- Per-city acc: Rotterdam 0.61 > Amsterdam 0.48 > Utrecht 0.43 > Delft 0.38

## Interpretation

**Win — year/period (anchor hypothesis cleanly confirmed).** MAE halved
(61.5→30.7) and period_acc improved 15.6× (0.049→0.769). Period accuracy is
the quantity the downstream TABULA matching actually consumes; it moved from
"systematically wrong" to "3 in 4 correct". Removing the boundary years from
the prompt eliminated the banding entirely.

**Flat — type (genuine zero-shot ceiling).** macro_f1 0.246 is marginally
below v2's 0.272. The hold-out is 88% AB, so v2's degenerate all-AB strategy
collected acc 0.774 and a high AB f1 for free; v3 answers honestly and sends
775 of 1,775 AB buildings to TH (canal-house-style subdivided apartments that
look exactly like terraced houses), leaving TH precision at 6%. On the
class-balanced dev sample v3 clearly beats v2-style behaviour (macro_f1
0.361), but on an AB-dominated test set the degenerate strategy wins the
metric. Paper-worthy observation: accuracy rewards the degenerate strategy;
macro-F1 plus a balanced sample is needed to see real behaviour. The
administrative definition (internal subdivision) is fundamentally not visible
from the facade — a hard ceiling for zero-shot 4-class Dutch typology.
