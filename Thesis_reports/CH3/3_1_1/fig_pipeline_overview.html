Fig. 3.1 — End-to-end methodological workflow. Two tracks are built independently and then joined. The reference track combines BAG, EP-Online and 3DBAG into a building reference table; the imagery track turns Mapillary Street-View Imagery (SVI) and building footprints into per-building facade crops, producing an SVI manifest keyed by the BAG pand_id, as detailed in Fig. 3.3. The two meet at an inner join on pand_id, so the linked dataset contains only buildings for which both a reference record and usable imagery exist. Attribute inference then derives the building type and construction year from the crops using the vision models of §3.3, and the resulting size class and period are mapped deterministically to a TABULA-NL cell supplying the as-built envelope U-values. The assembled attributes and U-values are finally passed to a fixed LightGBM evaluator that outputs the EPC prediction. The figure shows the processing chain only: the comparison routes, feature admission tiers and evaluation design that operate on this chain are defined in §3.5 and §4.1.2, and the counts surviving each filtering step are given in Table 3.2.
