Fig. 3.2 — Three-layer structure of the semi-synthetic dataset. Each building occupies one row, keyed by the BAG pand_id. The reference layer holds administrative records, reconstructed 3DBAG geometry and the EP-Online EPC reference label; the vision-inference layer holds the building-level type, year and floor predictions of each vision paradigm together with their model provenance and an explicit “unreadable” state; the synthetic archetype layer holds the construction period derived from the year, the resulting TABULA-NL cell and the four as-built envelope U-values assigned to that cell. Because the same deterministic lookup is applied once per route, the archetype layer is stored twice per building — shaded blue when derived from the reference attributes (M1) and teal when derived from the inferred attributes (M3). Row 2 shows the propagation the design is built to expose: a 13-year year error crosses the NL.01/NL.02 boundary, moves the building into a different cell and therefore changes every assigned U-value, while the reference and target columns stay fixed. Row 4 shows the unreadable state, which leaves the M3 cell unassigned rather than guessed. M2 is drawn outside the table because it writes no field in any of the three layers; it consumes the SVI crops and is scored against the same target column. Row values are illustrative and pand_ids are abbreviated (prefixes 0363, 0599, 0344 and 0503 denote Amsterdam, Rotterdam, Utrecht and Delft); the U-values are the actual TABULA-NL as-built values of the cells named (data/processed/tabula_nl.csv, provenance per value in Appendix A).
