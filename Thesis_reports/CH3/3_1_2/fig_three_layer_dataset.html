Fig. 3.2 — Three-layer structure of the semi-synthetic dataset. Each building occupies one row, keyed by the BAG pand_id. The reference layer holds the registry attributes and the EP-Online EPC label; the vision-inference layer holds the attributes predicted from the street-view crops together with the model that produced them; the synthetic archetype layer holds the TABULA-NL cell and its four as-built envelope U-values in the order wall, roof, floor, window. Because the same deterministic lookup is applied once per route, the archetype layer is stored twice per building: once derived from the reference attributes (M1) and once from the inferred attributes (M3). Reading the two archetype columns against each other shows how an attribute error does or does not reach the parameters. In the first row a twenty-year error in the estimated year stays inside the same period, so cell and U-values are unchanged. In the second a five-year error crosses the NL.04/NL.05 boundary and moves the building to a different cell, changing all four U-values. In the third the size class is wrong while the period is right, so the cell changes but the assigned U-values happen to be identical, because in the Dutch matrix the envelope values vary with period rather than with size class. In the fourth both attributes are wrong and the substituted parameters diverge sharply from the reference ones.

Provenance. All four rows are actual hold-out buildings, not illustrative values. Reference attributes and predictions are taken verbatim from reports/stage1/dinov2_frozen/holdout_preds.parquet (frozen DINOv2 probe, pooled hold-out); the EPC label from data/processed/stage1_gt.parquet; the U-values from data/processed/tabula_nl.csv, reproduced exactly as stored, with per-value provenance in Appendix A. Predicted years are regression outputs shown rounded to the nearest year and predicted floor counts to one decimal; the period is derived from the unrounded prediction. The label of the second row is registered as A+ and merged into class A under the rule stated in §3.2.1.
