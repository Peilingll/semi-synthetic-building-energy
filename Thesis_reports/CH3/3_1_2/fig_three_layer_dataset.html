Fig. 3.2 — Three-layer structure of the semi-synthetic dataset. Each row pairs one building, keyed by the BAG pand_id, with one vision configuration, two rows per configuration. The reference layer holds the registry attributes and the EP-Online EPC label; the vision-inference layer holds the attributes predicted from the street-view crops together with the model that produced them; the synthetic archetype layer holds the TABULA-NL cell and its four as-built envelope U-values in the order wall, roof, floor, window. Because the same deterministic lookup is applied once per route, the archetype layer is stored twice per building: once derived from the reference attributes (M1) and once from the inferred attributes (M3). Reading the two archetype columns against each other shows how an attribute error does or does not reach the parameters. Each vision configuration is shown on two hold-out buildings: one where the prediction errors stay inside the reference cell, and one where they do not. In the first DINOv2 row a twenty-year error in the estimated year stays inside the same period, so cell and U-values are unchanged; in the second a five-year error crosses the NL.04/NL.05 boundary and moves the building to a different cell, changing all four U-values. For ResNet-50 and InternVL3-2B the changed row is in each case a size-class error inside NL.01 — the one period in which the Dutch matrix distinguishes the terraced house, the envelope values otherwise varying with period rather than with size class — so the cell change carries through to the U-values. The trailing dots stand for the remaining hold-out buildings; the full table holds one row per building and vision model.

Provenance. All six rows are actual hold-out buildings, not illustrative values. Reference attributes and predictions are taken verbatim from reports/stage1/dinov2_frozen/holdout_preds.parquet (rows 1–2, frozen DINOv2 probe), reports/stage1/resnet50_ft/holdout_preds.parquet (rows 3–4, fine-tuned ResNet-50) and reports/stage1/vlm_internvl3/v3_holdout_per_pand_id.parquet (rows 5–6, InternVL3-2B, per-building vote), all pooled hold-out; the EPC label from data/processed/stage1_gt.parquet; the U-values from data/processed/tabula_nl.csv, reproduced exactly as stored, with per-value provenance in Appendix A. For the two trained models the predicted years are regression outputs shown rounded to the nearest year and predicted floor counts to one decimal, with the period derived from the unrounded prediction; the InternVL3-2B attributes are already integers, produced by the per-building vote over image-level answers. The label of the second row is registered as A+ and merged into class A under the rule stated in §3.2.1.
