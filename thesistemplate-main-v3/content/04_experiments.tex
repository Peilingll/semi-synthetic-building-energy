\chapter{Experiments and Evaluation}
\label{ch:experiments}

This chapter evaluates the four method stages through one evaluation setup and three experiments. Stage 1 establishes the experimental dataset, reference records, and data partitions used in the evaluation. Experiment I evaluates the three building attributes predicted in Stage 2. Experiment II evaluates the archetype cells and thermal parameters produced in Stage 3. Experiment III compares the energy class prediction procedures implemented in Stage 4. The Experimental Design and Results sections follow the same experiment order, creating a direct link between every comparison, metric, and reported result. The chapter closes with a discussion of the findings, their relation to prior work, and the limits of the evidence.

\subsection{Evaluation Setup}
\label{sec:dataset_statistics}

The evaluation setup fixes the building partitions before any metrics are calculated. This prevents differences among experiments from reflecting different data partitions. Unless stated otherwise, building counts refer to unique \texttt{pand\_id} values. The \ac{SVI} manifest contains 10,104 buildings and 47,238 images. Restricting the manifest to the eligible reference set and requiring valid 3DBAG geometry and TABULA-NL inputs yields an experimental dataset of 10,086 buildings and 47,150 images. The building-level split defined in Stage 1 assigns 8,068 buildings to the development set and 2,018 to the fixed holdout set. All images of one building remain in the same set.

The denominator is defined separately for each comparison before metrics are calculated. The two supervised configurations return predictions for all 2,018 holdout buildings, while InternVL3-2B returns valid predicted building attributes for 2,016. Experiment I therefore reports the available denominator for each configuration. Experiment III uses the comparison subset of 2,016 buildings for which every reference attribute, predicted attribute, and direct image condition is available. The thermal comparison in Experiment II additionally requires valid reconstructed areas, leaving 2,016 buildings for the two supervised configurations and 2,014 for InternVL3-2B. These exclusions are applied before condition comparison and are not selected from the observed prediction errors.

Two data checks define the validity boundary of the experiments. First, the experimental dataset is described by study area, building type, construction period, floor count, and registered energy class, and is compared with the eligible reference set of 124,784 buildings from the same four study areas. Second, the consistency of a building-level energy class is evaluated for buildings linked to multiple EP-Online certificates. The certificate check reports the prevalence of multiple records, disagreement among their classes, the modal class share, agreement between the latest and modal classes, and variation in the continuous energy indicator. These checks describe the evaluation target and do not alter the reference class used for model assessment.

\subsection{Experiment I: Building Attribute Prediction}
\label{sec:prediction_tasks_metrics}

Experiment I is needed to establish the accuracy of the predicted building attributes before they enter later stages. ResNet-50 with full fine tuning, DINOv2 with a frozen backbone and trained prediction heads, and InternVL3-2B without parameter updating are evaluated using the holdout set. Each configuration predicts building type, construction year, and floor count. The comparison concerns the complete vision configurations because their architecture, adaptation procedure, image limit, and image aggregation differ. Configuration-specific denominators are reported when valid outputs are unavailable.

\paragraph{E1a: Building type.}
Building type is a four-class prediction task covering Single Family House (SFH), Terraced House (TH), Multi Family House (MFH), and Apartment Block (AB). Macro F1 is the principal metric because it gives equal weight to each class. Accuracy is reported as a complementary metric, while class recall and the confusion matrix reveal whether a high aggregate value is concentrated in the dominant AB class.

\paragraph{E1b: Construction year and TABULA period.}
Construction year is evaluated using mean absolute error (MAE) and the coefficient of determination, $R^2$. MAE reports the average error in years, while $R^2$ measures the captured variation relative to prediction of the evaluation mean. Each predicted and reference year is also mapped through the same TABULA-NL period function. Period accuracy then reports the proportion of buildings assigned to the reference construction period, because a year error affects Stage 3 only when it changes the period.

\paragraph{E1c: Floor count.}
Floor count is evaluated using MAE and $R^2$. The two metrics distinguish a small average deviation from genuine recovery of building-level variation in a holdout set with a restricted floor count range. The generated reports also provide rounded exact agreement and agreement within one floor as supplementary checks.

For the four primary attribute metrics computed directly from predictions, uncertainty is estimated using 1,000 bootstrap resamples of buildings with random seed 42. Resampling at building level prevents several images of one building from entering a bootstrap sample as independent observations.

\subsection{Experiment II: Archetype Assignment and Thermal Consequences}
\label{sec:weighted_archetype_metric}

Experiment II is needed because separate attribute scores do not show whether type and year are correct for the same building or how a cell error changes the assigned thermal properties. It therefore contains two connected evaluations. E2a measures agreement with the reference TABULA-NL cell. E2b converts the reference and predicted cells to representative U-values and compares their implications for transmission heat transfer. A local window-to-wall ratio sensitivity check tests whether the assumed facade split changes the model ranking.

\paragraph{E2a: Joint archetype cell assignment.}
The TABULA-NL cell depends jointly on residential size class $s$ and construction period $p(y)$. Joint accuracy is therefore defined as

\begin{equation}
	\label{eq:joint_acc}
	\mathrm{JointAcc}
	= \frac{1}{n}\sum_{i=1}^{n}
	\mathbf{1}\!\left[\hat{s}_i = s_i \;\land\; p(\hat{y}_i) = p(y_i)\right].
\end{equation}

Uniform assignment across the 24 cells has an expected accuracy of $1/24 \approx 0.042$. A second baseline assigns every building to the most frequent reference cell. Macro cell recall is also reported as the unweighted mean recall across occupied cells. Joint accuracy measures overall agreement, while macro cell recall reveals performance outside the dominant cells.

\paragraph{E2b: Thermal consequences of cell assignment.}
Categorical cell agreement gives equal weight to errors between thermally similar and thermally different cells. The second evaluation therefore compares the floor-area-normalised transmission heat transfer coefficient $h_{tr}$ obtained from the reference and predicted cells. The notation follows the distinction between an overall transmission heat transfer coefficient and its value per square metre of reference floor area in the TABULA calculation method \parencite{loga2013calculation}. The comparison uses the U-values assigned by the relevant TABULA-NL cell, reconstructed 3DBAG areas, and the same window-to-wall ratio (WWR) in both calculations. Shared walls are treated as adiabatic.

For building $i$, the comparison quantity is

\begin{equation}
	\label{eq:htr}
	\begin{split}
		h_{tr,i} = \frac{1}{A_{floor,i}} \Bigl[
		 & U_{wall,i}A_{wall,i}(1-\mathrm{WWR}) + U_{window,i}A_{wall,i}\,\mathrm{WWR} \\
		 & + U_{roof,i}A_{roof,i} + U_{floor,i}A_{ground,i} \Bigr],
		 \qquad [\mathrm{W/(K\,m^2)}] .
	\end{split}
\end{equation}

The equation is evaluated twice for every building. One calculation uses U-values from the reference cell and the other uses U-values from the predicted cell; reconstructed areas and WWR remain fixed. Agreement is evaluated using MAE and

\begin{equation}
	\label{eq:htr_r2}
	R^2_{h_{tr}}
	= 1 - \frac{\sum_i\left(h_{tr,\mathrm{pred},i} - h_{tr,\mathrm{ref},i}\right)^2}
	{\sum_i\left(h_{tr,\mathrm{ref},i} - \overline{h_{tr,\mathrm{ref}}}\right)^2}.
\end{equation}

Weighting each floor-area-normalised value by $A_{floor}$ converts it to the corresponding building-level contribution before aggregation. Dividing the aggregate difference by the reference aggregate expresses the result as a relative percentage. This study therefore defines the floor-area-weighted relative difference as

\begin{equation}
	\label{eq:area_weighted_difference}
	\Delta_{A,h_{tr}}
	= \frac{\sum_i h_{tr,\mathrm{pred},i}A_{floor,i} - \sum_i h_{tr,\mathrm{ref},i}A_{floor,i}}
	{\sum_i h_{tr,\mathrm{ref},i}A_{floor,i}} .
\end{equation}

A positive value means that cells assigned from image predictions produce a larger aggregate transmission heat transfer coefficient than cells assigned from reference attributes, while a negative value means the opposite. The metric compares two archetype assignments and is not a validation against measured heat loss or energy use. \paragraph{E2c: WWR sensitivity.}
The primary calculation uses $\mathrm{WWR}=0.25$. Because reconstructed 3DBAG facades do not identify individual window openings, the calculation is repeated with WWR values of 0.15 and 0.35 while all other inputs remain fixed. This symmetric local variation tests the stability of the comparison and is not treated as a probabilistic uncertainty analysis \parencite{pang2020}.

\subsection{Experiment III: Energy Class Prediction}
\label{sec:information_source_conditions}

Table~\ref{tab:evaluation_conditions} defines the three energy class prediction conditions and the analytic baseline. The reference and predicted attribute conditions use the same fitted \acs{LightGBM} classifier. Their difference therefore isolates the change from reference to predicted building type, construction year, floor count, and the U-values selected by type and year. The direct image condition uses a separate image classifier and represents an alternative prediction procedure rather than an isolated input substitution.

\paragraph{E3a: Binary energy class prediction.}
The primary target distinguishes classes A to C from classes D to G. Separate classifiers are trained for this target rather than collapsing predictions from the seven-class task. The principal metric is macro F1 at a probability threshold of 0.5. Macro precision, macro recall, and recall for classes D to G describe performance across the two class groups.

\paragraph{E3b: Seven-class energy class prediction.}
The secondary task predicts classes A to G after ratings above A are combined with class A. Macro F1 is the principal class-balanced metric. Exact accuracy is reported for comparability with previous work, and $\pm1$ accuracy reports the proportion of predictions within one adjacent class of the registered value. Because the majority class alone attains a $\pm1$ accuracy of 0.612 on the comparison subset, this metric is interpreted only with macro F1 and both random and majority baselines.

\paragraph{E3c: Feature contribution analysis.}
A feature contribution analysis is needed to identify which structured inputs support energy class prediction. Leave-one-out ablation on the development set measures the change in macro F1 when construction year, building type, floor count, the four TABULA U-values, or study area is removed from the reference input set. Clean reconstructed geometry features are added separately to test whether information absent from the main eight inputs changes prediction performance. All ablation models use the same five development folds, fixed LightGBM settings, and no class weighting.

\section{Discussion}
\label{sec:discussion}

The three experiments answer different points in the same information chain. Experiment I shows that SVI can support building type, construction year, and floor count prediction, but performance depends on the vision configuration and class representation. Experiment II shows that errors in type and year affect both joint archetype assignment and the representative thermal properties assigned to a building. Experiment III shows that direct image prediction and prediction from building attributes produce different intermediate outputs and energy class results. The following discussion interprets these findings in experiment order.

\subsection{Building Attribute Prediction}

DINOv2 with a frozen backbone provided the most consistent attribute results, despite updating fewer parameters than the fully fine-tuned ResNet-50. ResNet-50 attained higher type accuracy because it performed strongly on the dominant AB class, but DINOv2 attained higher macro F1 and higher recall for SFH and TH. This difference confirms that accuracy alone is not an adequate summary for the present type distribution. The result supports use of a frozen self-supervised representation when labelled development data are limited, but it does not isolate the effect of pretraining from architecture or aggregation because the experiment compares complete configurations.

Construction year was the strongest continuous prediction target for DINOv2, with an $R^2$ of 0.679. This value is close to the 0.710 reported by \textcite{liang2025} for a fully fine-tuned InternVL3-2B model, but the datasets, label sources, and training procedures differ, so the values are not a direct benchmark. The negative $R^2$ of the InternVL3-2B configuration in this study instead shows that prompting without parameter updates did not recover building-level year variation among the evaluated Dutch buildings. The selected examples further suggest that visibility, occlusion, and viewpoint are relevant failure conditions, although a systematic image quality experiment would be required to quantify their effects.

\subsection{Archetype Assignment and Thermal Consequences}

The joint cell result requires interpretation against both baselines. Joint accuracies above 0.82 appear high relative to uniform assignment, but the majority cell alone reaches 0.790 because the holdout is dominated by old apartment blocks. Macro cell recall below 0.18 shows that the trained configurations had low recall for less frequent combinations of building type and construction period. This finding is consistent with earlier studies that identified building type and construction period as important sources of error in energy models based on archetypes \parencite{dochev2020,bass2022}. The present experiment adds a comparison in which predicted and reference building attributes refer to the same building records.

The $h_{tr}$ comparison distinguishes cell errors by their thermal consequence. It separated DINOv2 from InternVL3-2B more clearly than joint accuracy. All three predicted cell sets produced higher aggregate transmission heat transfer coefficients than the reference assignments. The construction year scatter provides a plausible explanation: several newer buildings were assigned to earlier periods with higher representative U-values. This explanation is consistent with the observed prediction pattern, but the analysis does not establish that the reference archetype values equal the measured envelope properties of those buildings.

The stable ranking across the three tested WWR values shows that the comparative result is not determined by the selected local facade split. It does not remove other physical uncertainties. The calculation excludes thermal bridge surcharges, uses reconstructed rather than measured areas, treats shared walls as adiabatic, and assigns the unrenovated TABULA-NL variant to every building. The $h_{tr}$ result should therefore be read as a physically weighted difference between two cell assignments, not as a validated estimate of actual heat demand.

\subsection{Energy Class Prediction}

Direct DINOv2 achieved the highest macro F1 for both energy class targets. This pattern is compatible with earlier evidence that street view images contain information associated with registered energy performance \parencite{mayer2023uk,mayer2023dk}. The present comparison does not show which additional visual cues produced the advantage, because the direct image condition does not produce building attributes. Possible cues include facade condition, window appearance, and surrounding context, but testing these explanations would require targeted labels or ablations.

The reference and trained predicted attribute conditions produced nearly equal binary macro F1. This small difference does not mean that attribute errors were physically negligible. Experiment II shows measurable cell and $h_{tr}$ differences, while Experiment III shows that the structured classifier had limited discrimination for classes D to G even when reference attributes were supplied. The feature ablation provides the same distinction. Construction year contributed the largest marginal change among the eight structured inputs and should therefore be prioritised when improving building attribute prediction from \ac{SVI}. The TABULA U-values added almost no independent information once building type and construction period were already present because the lookup is deterministic. Clean reconstructed geometry produced a larger improvement, indicating that the restricted structured input set omits information relevant to the registered class.

The seven-class results were low for all information sources when measured by macro F1. The reference attribute condition attained higher exact and $\pm1$ accuracy because its predictions were concentrated around frequent classes, whereas direct DINOv2 distributed more correct predictions across the class set. The concentration of the experimental dataset in frequent classes and archetype cells limits the interpretation of these aggregate results. The low macro F1 and class-specific recalls show that performance was not uniform across the registered energy classes.

\subsection{Validity, Limitations, and Future Evaluation}
\label{sec:validity_limitations}

The first limitation concerns the composition and geographic scope of the experimental dataset. Mapillary availability and image filtering produced a dataset dominated by Amsterdam and AB buildings, with few observations for several residential types, construction periods, archetype cells, and energy classes. The results therefore apply to the evaluated buildings with at least one image meeting the Stage 1 selection rules and do not establish performance for a study area excluded from model development. Future geographic evaluation should exclude each study area from model development in turn and report the composition and class-specific performance of every target set. Application outside the Netherlands additionally requires explicit mappings among national registries, energy class definitions, and archetype taxonomies before model transfer can be assessed.

The second limitation arises from the difference between the certificate unit and the unit of analysis. EP-Online certificates are registered for dwellings, whereas this study evaluates BAG buildings. Stage 1 reduces the linked records to one registered energy class per BAG building, which gives every building one target label in the experimental dataset. However, 58.4\% of the 10,075 buildings linked back to the raw certificate records had multiple certificates, and 77.0\% of that group contained more than one class. Selecting the latest certificate provides one reproducible target but does not remove variation among dwelling units or registration dates. The target may therefore describe one unit or one recorded state rather than the facade and geometry observed for the complete building. Mapillary acquisition dates were also not systematically aligned with certificate registration dates, which can add temporal disagreement between an image and its target. Future evaluation should distinguish single unit and multiunit buildings, compare latest, modal, and unit level targets where linkage permits, and align image and certificate dates where possible.

The third limitation concerns model comparison. The three vision configurations differ in architecture, pretraining, parameter updates, image count, and aggregation, so their performance cannot be attributed to one design choice. Hyperparameters were not exhaustively optimised for every target, and InternVL3-2B was evaluated without parameter updating. In addition, the direct image and building attribute prediction procedures use different model families. Their results therefore compare complete prediction procedures rather than isolating the effect of information source alone. Future experiments should include an open-source \ac{VLM} fine-tuned on the experimental data, repeated training with several random seeds, matched image aggregation, class imbalance treatments, ordinal construction period prediction, calibration analysis, and systematic hyperparameter optimisation.

The fourth limitation concerns archetype mapping and physical interpretation. The operational mapping converts six EP-Online residential categories into four TABULA-NL size classes, including semi-detached houses within SFH and apartments within AB, but alternative mappings were not examined. TABULA-NL then assigns representative as built properties by size class and construction period, while refurbishment state is unavailable consistently for individual buildings. \Ac{SVI} may show visible facade or window changes but cannot verify concealed insulation, heating system upgrades, or renovations within individual units. The thermal comparison also relies on reconstructed 3DBAG geometry, a fixed WWR range, and archetype U-values rather than measured envelope properties. Future physical evaluation should incorporate verified renovation records, measured envelope properties, and independent heat demand observations. Any comparison with measured consumption must also control for weather, occupancy, floor area, and heating systems before differences are interpreted as evidence of renovation or archetype error.

These limitations define a bounded practical implication. \Ac{SVI} can provide useful building attributes when reference building attributes are missing, and those attributes can be connected to a transparent archetype workflow. For the evaluated energy class task, however, building type, construction year, floor count, and their TABULA-NL U-values do not contain all information required for class-balanced prediction. A practical workflow should use administrative records and reconstructed geometry where they are available, use \ac{SVI} to supplement building attributes that can be inferred from visible facades, and report uncertainty for sparsely represented building groups.
